# ISO/IEC 29110 Entry Profile (ISO/IEC TR 29110-1, 29110-4-1, 29110-5-1-1)

## VSE — Very Small Entity Tanımı

> Enterprise, organization, department or project with **up to 25 people**.

Sık atıf yapılan yaklaşık istatistikler (ISO/IEC TR 29110-1 ve sektör raporları):
- %90 dünya işletmeleri SME (small/medium)
- %60 küresel istihdam SME'lerden
- %93.5 EU'da micro firms (<10 kişi)

## VSE'lerin Karşılaştığı Sorun

> "Traditional Standards Don't Fit"

- Çoğu uluslararası standart büyük org. için tasarlanmış
- Aşırı karmaşık process'ler
- Resource-intensive gereksinimler
- Standartları iş ihtiyaçlarıyla ilişkilendirmek zor

## Profil Yol Haritası

| Profil | Hedef VSE | Özet |
|--------|-----------|------|
| **Entry** | Start-up + küçük proje (<6 person-months) | Bu skill'in odağı |
| Basic | Established VSE, standart yazılım dev. | Sonraki seviye |
| Intermediate | Büyüyen VSE, sofistike process'ler | – |
| Advanced | Olgun VSE, kompleks proje | – |

## Entry Profile Hedef Kitle

- **Start-up VSE'lar:** 3 yıldan kısa, formal process deneyimi sınırlı, hızlı uygulama, MVP odak
- **Küçük takım projeleri:** <6 person-month efor, sınırlı kaynak/bütçe, tight deadline, simple-moderate complexity

## 2 Çekirdek Process

### Project Management (PM)

> Establishes and carries out systematic project tasks to achieve objectives within quality, time, scope and cost constraints.

| Activity | Tanım | Outcomes |
|----------|---------------|----------|
| **PM.1 Project Planning** | Müşteri anlaşmasından kapsamlı proje planı | Project Plan, Repository setup |
| **PM.2 Plan Execution** | Plana göre uygulama, ilerleme izleme | Plan-driven execution kayıtları |
| **PM.3 Assessment & Control** | Performans değerlendirme + düzeltici aksiyon | Statü raporları, action items |
| **PM.4 Project Closure** | Ürün teslimi + müşteri kabulü | Acceptance record |

### Software Implementation (SI)

> Systematic performance of requirements analysis, design, construction, integration, testing, and assembly activities.

| Activity | Tanım |
|----------|-------|
| **SI.1 Implementation Initiation** | Proje planını gözden geçir, ortam kur |
| **SI.2 Software Requirements Analysis** | Müşteri requirement'larını analiz + doğrula |
| **SI.3 Software Component Identification (Design)** | Bileşenleri ve interface'leri belirle/tasarla |
| **SI.4 Software Construction** | Kod modülleri + unit test |
| **SI.5 Software Integration & Tests** | Entegrasyon + test |
| **SI.6 Product Delivery** | Müşteriye teslim |

## Entry Conditions

İki giriş koşulu:
1. **Team Assignment** — proje takımı (PM dahil) atanmış ve eğitilmiş
2. **Development Cycle Documentation** — yaklaşım dokümante edilmiş (waterfall/iterative/incremental/evolutionary/agile)

Bu iki koşul sağlanmadan Entry Profile uygulanamaz.

## Roller

| Rol | Açıklama |
|-----|----------|
| **Customer (CUS)** | Requirement bilgisi, onay otoritesi, kullanıcı ihtiyaçlarını temsil. Domain uzmanlığı + iş süreçlerini açıkça anlatabilir. |
| **Project Manager (PM)** | Liderlik, karar verme, planlama, personel yönetimi, yazılım geliştirme bilgisi. |
| **Work Team (WT)** | Teknik beceri. |

## Essential Work Products

| Work Product | Açıklama |
|--------------|----------|
| Project Plan | Tasks, resources, schedule, delivery instructions |
| Requirements Specification | Müşteri ihtiyaçları, validated |
| Software Design | Bileşenler + interface'ler |
| Software Components | Kaynak kod |
| Test Cases & Procedures | Test paketi |
| Software Configuration | Versiyon kontrolü, branching |
| Project Repository | Tüm artefaktların saklandığı yer |
| Maintenance Documentation | Sürdürülebilirlik için |

## 12207 ile Karşılaştırma

| Boyut | ISO/IEC 12207 | ISO/IEC 29110 Entry |
|-------|---------------|----------------------|
| Tasarım hedefi | Tüm organizasyonlar | VSE'lara özel |
| Process sayısı | 30 (4 grup) | 2 (PM + SI) |
| Tailoring | Manuel, uzmanlık gerekir | Pre-tailored, hazır |
| Karmaşıklık | Kompleks | Lightweight + pratik |
| Yaşam döngüsü kapsamı | Tüm sistem | Yazılım odaklı |

## Uyum Yüzdesi Hesabı

```
PM uyumu = (uygulanan PM activity sayısı) / 4 × 100
SI uyumu = (uygulanan SI activity sayısı) / 6 × 100
Genel = ortalama
```

Hedef: ≥ %75 her iki process için.
